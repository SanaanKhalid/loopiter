---
title: Security and privacy
---

Loopiter sends no telemetry. The core does not call any provider. The optional live
starter sends selected text to OpenAI or Azure OpenAI using your credentials; it requires explicit live
selection and configured model. `store:false` is not zero retention, consent or
compliance certification. Review provider terms and your data governance first.

## Before persistence

Configure `maximumPayloadBytes` (default 262,144) and a deterministic
`sanitize(json) → json` hook on the client. Inputs and sanitized outputs are validated;
if the hook throws, no raw fallback is saved. Capture, completions, candidates,
evaluation results and deployment receipts use the hook. Hook failure during receipt
finalization leaves an external outcome pending, to reconcile after remediation.

The hook is not a full PII detector or access-control engine. Avoid secrets in record
IDs, namespaces, actor IDs, reasons and artifact/version identifiers; these operational
fields are not anonymized automatically. Delete raw sensitive fields before they reach
the SDK. A sanitizer must preserve required identities, hashes and receipt bindings.
Store only data you have authority to retain and send to your chosen processors.

## Trust boundaries

Namespace binding prevents accidental unscoped SDK access; it does not authenticate
the caller or stop a malicious process holding the database credentials. Authorize
namespace and target access in your service. Use distinct development/production
namespaces and least-privilege database/provider/deployment credentials.

Verify correction sources. Treat prompts, examples and model outputs as untrusted
data, not instructions that may change policy, evaluator thresholds or deployment
authorization. Conflicting/poisoned feedback can degrade a system even when JSON is
valid. Keep human review and independent holdouts appropriate to the risk.

Callbacks are ordinary JavaScript. Timeouts are cooperative cancellation, not a
sandbox, resource jail or forced kill. Isolate untrusted callbacks separately. Risk
labels are not a security boundary. Autonomous execution requires an explicit flag,
exact prompt/routing target policy, independent audit and production observation.
Proposals cannot alter trusted policies, labels, safety instructions or evaluator thresholds.

## Deletion and reporting

`loop.deleteNamespace(exactNamespace)` explicitly erases that namespace's Loopiter
history. Stop writers and reconcile pending deployments first. This does not remove
external artifacts, OpenAI copies, logs or backups. No automated retention service runs.

Report security issues through the repository's private vulnerability-reporting flow
when enabled. If unavailable, request a private channel without posting secrets or
exploit details in a public issue. See `SECURITY.md`. The maintainer must verify that
reporting is enabled before public launch. There is no alpha SLA or security certification.
